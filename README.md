# Security Data Analyst — Índice del programa

Este repositorio contiene el plan completo de 90 sesiones. Usa el índice para abrir la teoría y la evaluación de cada día. El flujo de estudio es: teoría → práctica guiada → evaluación interactiva con IA → registro de evidencia en el cuaderno. El archivo `curriculum/session-plan.md` se conserva como fuente operativa original del currículo.

## Reglas de trabajo

- Sigue el objetivo, los recursos y la práctica definidos para cada sesión.
- Trabaja únicamente con datos sintéticos y entornos propios o autorizados.
- Guarda en `evaluaciones.md` la nota, el feedback y tu reflexión después de completar cada evaluación.
- No avances si no puedes explicar el resultado; registra las limitaciones y lo que queda pendiente.
