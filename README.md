# Calendario de estudio — Security Data Analyst

Este repositorio organiza el aprendizaje en sesiones diarias. Cada día contiene teoría, una práctica guiada y una evaluación interactiva con IA. Al terminar, guarda el resumen de tu evaluación en el archivo de evidencia correspondiente mediante un commit en GitHub.

## Índice de los primeros 3 días

| Día | Tema | Guía |
|---|---|---|
| Día 01 | Cliente, Servidor y Ciclo HTTP | [Día 01 - HTTP](guia-estudio.md#dia-01---cliente-servidor-y-ciclo-http) |
| Día 02 | Modelo OSI y TCP/IP | [Día 02 - OSI y TCP/IP](guia-estudio.md#dia-02---modelo-osi-y-tcpip) |
| Día 03 | DNS y Resolución de Nombres | [Día 03 - DNS](guia-estudio.md#dia-03---dns-y-resolucion-de-nombres) |

## Flujo de trabajo diario

1. Lee la teoría y consulta la documentación recomendada.
2. Completa la práctica guiada y registra tus observaciones.
3. Copia el prompt de evaluación del día en ChatGPT o Claude y responde sin adelantarte a las preguntas.
4. Guarda el resumen y feedback de la IA en el archivo de evidencia del día.
